# To spec

Within that approval, resolve technical choices yourself and stop only for material product ambiguity, scope changes, or sensitive actions outside the approval.

## Process

1. Write out the spec as according to the original `to-spec-with-tech-detail` skill.

2. Write out the technical implementation notes section - this is the high-level overview of what the major techical decisions are, and how they will impact the system and how it all works together.
